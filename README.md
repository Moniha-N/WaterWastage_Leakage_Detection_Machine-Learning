Water Leakage Detection System

A Machine Learning based Water Leakage Detection System developed using Python and Logistic Regression. This project predicts water wastage conditions based on water usage patterns and user activity.

Features

- Detects possible water leakage or wastage
- Uses Machine Learning for prediction
- Displays prediction accuracy
- Shows confusion matrix and graph visualization
- Analyzes water usage conditions

Technologies Used

- Python
- Scikit-learn
- Pandas
- NumPy
- Matplotlib
- Logistic Regression

Input Parameters

- Tap Duration
- Frequency
- Time
- User Presence

Output

- Water Wastage Prediction (0/1)
- Accuracy Score
- Confusion Matrix
- Actual vs Predicted Graph

How It Works

1. Water usage data is processed using Python.
2. Logistic Regression model is trained using Scikit-learn.
3. The system analyzes tap usage patterns and user presence.
4. The model predicts whether water wastage is detected or not.
5. Results are displayed with graphical visualization.
